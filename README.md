# taiyaq

文化祭のたい焼き販売で使う、注文と受け取りの管理システム。
来場者は店頭に並んで注文し、整理券を受け取ります。
できあがりはWebページや店頭モニターで確認できます。

## 主な機能

### 来場者向け

- 整理券番号から自分の注文状況と待ち時間を確認
- Webページや店頭モニターで受け取り可能な番号を確認

### スタッフ向け

- 注文受付、焼き上がり登録、受け渡し、優先指定、保留と復帰、キャンセル
- 数量ボタンやキーボードによる操作
- 味ごとの販売切り替えと在庫の管理
- 日別の注文履歴の確認

通常は同じ味の商品を注文順に確保し、すべての商品が揃った注文を受け取り可能にします。
優先指定した注文には準備中の確保分も回し、受け取り可能になった注文の確保分は維持します。
整理券番号は1〜99を循環し、使用中の番号を飛ばして再利用します。

## ページ

| ページ       | URL      | 内容                                               |
| ------------ | -------- | -------------------------------------------------- |
| 来場者向け   | /        | 注文状況と待ち時間の確認                           |
| 店頭モニター | /display | 受け取り可能な整理券番号の表示                     |
| スタッフ用   | /staff   | 注文受付、焼き上がり登録、受け渡し、販売設定、履歴 |

## システム構成

画面はReact、サーバー処理はTypeScriptで実装し、Cloudflare
WorkersとD1で動作します。
